Software Design and Engineering (Enhancement One)

The artifact selected for the software design enhancement is an investment client management application originally created during a software reverse engineering course through the disassembly and reconstruction of a compiled binary executable. In its initial state, the program depended on global variables and hardcoded arrays, exposing sensitive data throughout its execution. This enhancement completely restructured the application into a modern, object-oriented architecture by organizing the code into modular header and implementation files, encapsulating customer data within dedicated classes such as Client, AuthenticationManager, and ClientManager, and strengthening input validation and error recovery to improve maintainability and security.

Algorithms and Data Structures (Enhancement Two)

The artifact for the algorithms and data structures enhancement builds upon the refactored client management application by optimizing data storage and search performance. The initial implementation relied on fixed memory slots and linear scanning, which resulted in a time complexity of O(N). To overcome this performance bottleneck, memory storage was transitioned into a dynamic C++ vector of Client objects, and standard library sorting utilities were applied to organize records alphabetically and numerically with an efficiency of O(N log N). Furthermore, a binary search lookup algorithm (lower_bound) was implemented to replace linear scans, reducing data retrieval complexity to O(log N) and ensuring that search operations scale smoothly as dataset sizes expand.
